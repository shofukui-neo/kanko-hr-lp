## Cloudflare Pages へのデプロイ

1. Cloudflare ダッシュボード → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
2. このリポジトリを選択
3. ビルド設定
   - Framework preset: **None**
   - Build command: （空欄）
   - Build output directory: `/`
4. **Save and Deploy** → 以降は `main` への push で自動デプロイ
